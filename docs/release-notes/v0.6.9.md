# Agent Workbench v0.6.9

## Fixed

- Container users now receive the image from the documented Auriora registry:
  `ghcr.io/auriora/agent-workbench`. The package manifest, installation
  guidance, runtime profile, and release workflow all use the same address.
- The cross-platform packaging check now builds the distributed runtime before
  launching it, matching the packaged installation path.
- The Windows launch check waits for the MCP process to stop before deleting
  its temporary workspace, avoiding a false `EBUSY` cleanup failure after a
  successful handshake.

## Validation

- The release contract check confirms that package metadata and GHCR
  publication target the same image.
- TypeScript type checking, focused integration tests, a local MCP launch, and
  the release preflight passed.
- GitHub Actions validated the native dependency install and runtime build on
  Windows before the corrected MCP launch check.

## Upgrade Note

- Container users should pull
  `ghcr.io/auriora/agent-workbench:0.6.9` or
  `ghcr.io/auriora/agent-workbench:latest`.
- Package users should install v0.6.9 so their bundled distribution metadata
  points to the published image.
