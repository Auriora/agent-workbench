# Agent Workbench v0.6.16

## Highlights

- Fixes graph refresh being blocked by unchanged files whose timestamps round
  across a millisecond boundary. This issue was found during installed-checkout
  validation after v0.6.15 passed its isolated release tests.

## Added

- Regression coverage for stable timestamp boundaries and genuine file changes.

## Changed

- Manifest preparation compares timestamps at the same precision as Node's
  numeric file metadata. Exact nanosecond identity and watcher checks remain
  authoritative for invalidation.

## Fixed

- Stable sub-millisecond file timestamps no longer produce false catalog
  metadata-change failures.

## Documentation

- Installation and release guidance identifies the corrective version and
  retains the guarded native-build and stopped-owner upgrade procedures.

## Validation

- Typecheck, targeted filesystem/manifest tests and an isolated complete-generation
  profile of the actual checkout validate the precision correction.
- Publication remains gated on fresh Linux validation and actual Windows native
  safety, build-contract and extracted-portable smoke tests.

## Known Issues

- Background CPU scheduling (B014), guarded build-tool dependency maintenance
  (B015) and further RSS characterization (B016) remain owned follow-ups.
- Python and a C/C++20 toolchain remain required for npm installation. Installing
  a package does not replace an already running daemon; restart client sessions
  to load refreshed plugins and follow the stopped-owner upgrade procedure.
