# Agent Workbench Claude Code Guidance

Before making a repository claim not already verified in the current session,
including a quick overview, invoke the packaged
`/agent-workbench:agent-workbench` skill when the Agent Workbench MCP server is
available. Skip it only when the task requires no repository evidence.

The skill teaches the provider-neutral authority, freshness, ranked-evidence,
and claim-boundary workflow; it does not invoke the runtime automatically or
add Claude-specific runtime behavior.
